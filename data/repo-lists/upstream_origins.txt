# Candidate non-GitHub origins for cohort repos, for scripts/identity/repo_identity.py.
#
# This file is a CANDIDATE GENERATOR, never evidence. Every line is verified
# by intrinsic ref overlap (git ls-remote, the same rule that merges any two
# origins) before it is recorded, and a line that fails is printed as a
# rejection rather than silently kept. A wrong guess here cannot produce a
# wrong merge.
#
# It exists because `git ls-remote` can verify an origin but cannot discover
# one, and Software Heritage's public REST API -- the natural place to ask
# "what else serves this revision" -- does not expose that query. Only a
# substring search over origin URLs, which does not surface
# git.kernel.org/.../linux.git for the query "linux" at all. Doing discovery
# properly means the SWH graph dataset on AWS Open Data, a separate project.
#
# Format: <github owner/name><TAB><candidate upstream URL>
# Lines starting with # are comments. Blank lines are ignored.
