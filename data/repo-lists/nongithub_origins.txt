# Debian source package -> upstream origin, for projects with no GitHub
# repository at all. Read by scripts/46_debian_dependency_edges.py.
#
# These are the repositories that ROADMAP Phase 21 had to leave out. They are
# not obscure -- libX11, cairo, dbus, mesa, wayland and fontconfig sit under
# most of a Linux desktop -- but every one of them publishes on
# gitlab.freedesktop.org, gitlab.gnome.org or sourceware, and the GitHub
# mirrors that exist for them are stale forks whose tags do not match what
# Debian ships. Under a node id that had to be an `owner/name` GitHub slug
# they were unreachable, so the most load-bearing region of the graph was
# missing its actual occupants.
#
# The node id for these is `host/path`, derived from the URL: a first segment
# containing a dot means a forge host rather than a GitHub owner. That is
# unambiguous rather than a convention -- GitHub owner names are
# [A-Za-z0-9-]+ and cannot contain a dot, checked against all 8,251 existing
# nodes.
#
# Corroborated exactly like every other candidate file here: the upstream
# version Debian ships must appear among the origin's own git tags. That check
# is forge-independent by construction, because `git ls-remote` is.
#
# Format: <debian source package><TAB><origin URL>
